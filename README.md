## 🎯 About The Project

This repository is designed to document my journey in mastering Core Java. Each directory contains modular Java programs, code snippets, notes, and practical exercises.

### 🌟 Key Features:

* 🧩 **Step-by-Step Modules:** Organized sequentially from basic syntax to advanced concurrency.
* 📝 **Clean Code & Comments:** Well-commented code explaining *why* and *how* logic works.
* ⚡ **Modern Java Support:** Practical examples using features from Java 8 through Java 17+ (Streams, Lambdas, Records, Var, etc.).
* 🛠️ **Mini Projects:** Small real-world applications consolidating concepts learned in each module.

## ⚙️ Prerequisites

To run the programs in this repository, ensure you have the following installed on your system:

* **JDK (Java Development Kit):** Version 17 or higher
  * Download from [Oracle JDK](https://www.oracle.com/java/technologies/downloads/) or [Eclipse Adoptium OpenJDK](https://adoptium.net/)
* **IDE:** IntelliJ IDEA / Eclipse / VS Code
* **Build Tool (Optional):** Maven or Gradle

Check your Java version:

```bash
java -version
javac -version
```

## 🚀 How to Run the Code

1. **Clone the repository:**

   ```bash
   git clone https://github.com/your-username/core-java-mastery.git
   ```

2. **Navigate into the project directory:**

   ```bash
   cd core-java-mastery
   ```

3. **Compile any Java file:**

   ```bash
   javac 01-Java-Basics/HelloWorld.java
   ```

4. **Run the compiled Java program:**

   ```bash
   java 01-Java-Basics/HelloWorld
   ```
